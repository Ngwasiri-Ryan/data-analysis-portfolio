# **App Name**: Data Insights Portfolio

## Core Features:

- Interactive Data Visualizations: Dynamic charts and graphs built with ECharts, Chart.js, and Plotly.js, animated to showcase data analysis projects and insights.
- Animated Resume Timeline: A visually engaging timeline of experience and education with animated nodes and glowing effects.
- Responsive Layout System: A 12-column grid that adapts fluidly across mobile, tablet, and desktop, maintaining aesthetic integrity and user experience.
- Interactive Project Case Studies: Featured projects with floating cards, animated charts, and case study access, designed for high engagement.
- AI-Powered Project Description Generation: LLM tool which generates concise descriptions of completed data analytics projects from structured data, ready for placement in project cards.

## Style Guidelines:

- Primary color: Deep ocean blue (#005AE0) for a sense of trust, authority, and intelligence, reflecting data-driven insights.
- Background color: Light bluish-gray (#F1F5F9) for a clean, modern, professional feel, and to put focus on the content.
- Accent color: Seafoam green (#14B8A6) for CTAs, providing contrast without being distracting.
- Headings font: 'Sora' (sans-serif) for headings (600-700 weight) – Note: currently only Google Fonts are supported.
- Body font: 'Inter' (sans-serif) for body (400-500 weight) – Note: currently only Google Fonts are supported.
- Numbers font: 'JetBrains Mono' (monospace) for clear presentation of numerical data. – Note: currently only Google Fonts are supported.
- Lucide Icons or Feather Icons for a clean, consistent, and modern look across the portfolio.
- Subtle fade-up entry animations, smooth scrolling reveals, and parallax effects to create an engaging, premium user experience.
- Glassmorphic panels and subtle data grid backgrounds for a sleek, modern interface with neo-brutalist accents.
